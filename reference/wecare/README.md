# Reference — wecare.gr (tracked derivatives only)

This directory contains **sanitized, tracked** derivatives of the public
reference-site analysis:

- `inventory/` — deterministic JSON metadata (page list, page types, link graph edges).
- `reports/` — human-readable Markdown summaries.

Raw HTML, screenshots, and runtime metadata are **local-only** under
`reference-private/wecare/` and are never committed. See
[`docs/reference/REFERENCE_POLICY.md`](../../docs/reference/REFERENCE_POLICY.md).

> All inventories are heuristic observations from a polite, capped,
> read-only crawl — not a complete or authoritative sitemap.
